# Прохождение уровня (GameplayFlow)

Сцена: `Assets/_Project/Scenes/GameplayFlow.unity` — **игровая сцена**: её открывает кнопка «Играть» в меню (`SceneNames.GameplayFlow`). Игровые системы (`GameLifetimeScope`, меню паузы на Esc, настройки) перенесены из `Game`.

## Порядок комнат

`SafeRoom` → `Light` → `Location_1..4` → `Boss`

Комнаты и коридоры закрыты потолком, между комнатами — коридоры с подъёмными дверями. У каждой комнаты своя тема и цвет подсветки: склад, серверная, лаборатория, генераторная, сборочный цех, ядро (см. [GameplayFlowBuilder.md](GameplayFlowBuilder.md#темы-комнат)). Над дверью в комнату — табличка с её номером и названием.

## Как играется

1. **SafeRoom** — боя нет. Следы прошлого боя, табличка с правилами и меч. Дверь в коридор открывается только после подбора меча.
2. **Коридор — безопасная зона.** Зашёл → дверь позади закрылась. Можно отдохнуть.
3. Подошёл к дальней двери → следующая локация запускается (враги уже на месте), дверь открывается.
4. Вошёл в комнату → дверь за спиной закрывается.
5. **Локация:** волны идут, пока цела хоть одна камера. Каждая волна сложнее предыдущей. Все камеры сломаны → новых волн нет, добиваешь оставшихся → выход открыт.
6. После `Boss` игра пройдена (`GameLoop.Completed`).

## Управление

| Клавиша | Действие |
|---|---|
| WASD | перемещение |
| ЛКМ | удар мечом (2.5 м перед камерой) |
| Esc | меню паузы |
| F1 | **debug:** убить всех врагов |
| F2 | **debug:** сломать камеры текущей локации |

F1/F2 работают только в редакторе и development-билде.

## Компоненты

| Компонент | Зачем |
|---|---|
| `LocationPassage` | коридор: двери, запуск следующей локации |
| `PassageZone` | триггер в коридоре, сообщает о входе игрока |
| `LocationDoor` | дверь поднимается / опускается |
| `WeaponPickup` | подбор меча, включает `MeleeWeapon` |
| `MeleeWeapon` | меч: удар по врагам и камерам |
| `DebugCheats` | F1 / F2 |

## Что настраивать

- **Сложность волн:** `Configs/Levels/<Комната>_WavesLoop` → `StatsGrowthPerWave` (рост хп за волну), `ExtraEnemiesPerRepeat` (враги за повтор).
- **Состав волн:** `Configs/Levels/<Комната>_Wave_N`.
- **Меч:** поля `MeleeWeapon` на игроке: урон, дальность, перезарядка.

Сцену собрал ИИ-генератор, см. [GameplayFlowBuilder.md](GameplayFlowBuilder.md). Если менять её руками, генератор больше не запускать: он перезапишет сцену.
