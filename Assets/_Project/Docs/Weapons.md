# Оружие и отладка

## Меч — `MeleeWeapon`

Висит на игроке. По **ЛКМ** — рубящий удар: `SphereCast` из `_aimTransform` вперёд. Всё, что задето:
- `Enemy` — получает `_damage` урона;
- `SecurityCamera` — получает один удар (`TakeHit()`).

Бьёт только при залоченном курсоре: клик по меню паузы не считается ударом.

| Поле | По умолчанию | Что это |
|---|---|---|
| `_aimTransform` | — | откуда и куда бить (`CameraTarget` игрока) |
| `_model` | — | модель меча в руке. Видна, только пока компонент включён |
| `_damage` | 50 | урон врагу |
| `_range` | 2.5 м | дальность удара |
| `_radius` | 0.5 м | толщина удара |
| `_cooldown` | 0.45 с | пауза между ударами |
| `_hitMask` | всё | какие слои бьём |

Модель меча: пивот у рукояти, клинок вдоль локальной оси **+Y**. Анимация удара — поворот модели в коде (`Swing`), аниматор не нужен.

Камеры наблюдения должны висеть на досягаемой высоте (в `GameplayFlow` — 1.9 м).

## Подбор — `WeaponPickup`

Предмет на уровне с триггером (`Is Trigger`). Крутится вокруг своей оси.

- В `Awake` выключает `_weapon` — до подбора оружия нет.
- Игрок с тегом `Player` вошёл в триггер → `_weapon` включается, событие `PickedUp`, предмет исчезает.
- `IsPickedUp` — подобран ли.

`_weapon` — любой `Behaviour`, обычно `MeleeWeapon`.

⚠ Триггер вешать на объект **без масштаба**: масштаб раздувает радиус сферы. Модель — дочерним объектом.

## Курсор — `CursorLocker`

Скрывает курсор со старта, Esc — отпустить, клик — залочить. Нужен только в тестовых сценах без `GameLifetimeScope`. В игровой сцене курсором управляют `GameEntryPoint` и меню паузы — `CursorLocker` туда **не** добавлять, иначе клики по меню будут прятать курсор.

## Отладка — `DebugCheats`

Работает только в редакторе и development-билде, внизу экрана подсказка.

| Клавиша | Что делает |
|---|---|
| F1 | убить всех живых врагов |
| F2 | сломать камеры **текущей** локации (будущие не трогает) |

F2, потом F1 — локация сразу пройдена. Поле `_gameLoop` — откуда брать текущую локацию.
