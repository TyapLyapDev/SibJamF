# Коридоры и двери

Коридор между локациями — **безопасная зона**. Двери пропускают игрока только вперёд и только когда можно.

## Цикл коридора

```
предыдущая локация пройдена  ─→  выход открыт
игрок вошёл в коридор (SafeZone)  ─→  выход закрылся за спиной
подошёл к дальней двери (EntryApproachZone)  ─→  следующая локация запущена, дверь открыта
вошёл в комнату (RoomEntryZone)  ─→  дверь за спиной закрылась
```

Враги появляются **до** открытия двери: когда игрок заходит в комнату, бой уже идёт.

Стартовая комната (`SafeRoom`) не локация: у её коридора `_fromLocation` пуст. Выход открывается:
- после подбора оружия, если задан `_requiredPickup`;
- иначе сразу при старте.

## Компоненты

| Компонент | Зачем |
|---|---|
| `LocationPassage` | на корне коридора, ведёт весь цикл выше |
| `PassageZone` | триггер (`Is Trigger`), событие `Entered`, когда входит объект с тегом `Player` |
| `LocationDoor` | дверь: `Open()` / `Close()` плавно поднимают / опускают её. `IsOpen` |

### `LocationPassage`

| Поле | Что это |
|---|---|
| `_gameLoop` | через него запускается следующая локация (`LaunchLocation`) |
| `_fromLocation` | локация до коридора. Пусто — стартовая комната |
| `_requiredPickup` | только для стартовой комнаты: выход откроется после подбора этого `WeaponPickup` |
| `_toLocation` | локация после коридора |
| `_exitDoor` / `_entryDoor` | дверь выхода из прошлой комнаты / входа в следующую |
| `_safeZone` | зона сразу за дверью выхода |
| `_entryApproachZone` | зона перед дальней дверью |
| `_roomEntryZone` | зона уже внутри следующей комнаты, за дверью |

Защита от обхода:
- выход закроется, только если он уже был открыт (локация пройдена / оружие подобрано);
- дальняя дверь откроется, только если игрок прошёл `SafeZone`;
- каждая дверь срабатывает один раз.

### `LocationDoor`

| Поле | По умолчанию | Что это |
|---|---|---|
| `_liftHeight` | 4.5 | на сколько поднимается |
| `_duration` | 1.2 с | время подъёма / спуска |

`Open(callback)` / `Close(callback)` — колбэк вызывается, когда дверь доехала.

## Как добавить коридор вручную

1. Пол и стены коридора, в проёмах комнат — кубы с `LocationDoor`.
2. Три объекта-триггера с `PassageZone`: сразу за выходом, перед дальней дверью, внутри следующей комнаты (поперёк прохода, чтобы не обойти).
3. На корень коридора — `LocationPassage`, заполнить все поля.
4. У игрока должен быть тег `Player`.
