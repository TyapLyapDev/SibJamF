# Волны

Цикл: **волна → пауза → волна → …**

1. Волна спавнит врагов из своего конфига.
2. Когда все враги волны убиты, начинается пауза.
3. После паузы стартует следующая волна.
4. После последней волны:
   - `RepeatLastWave` включён — последняя волна повторяется бесконечно;
   - выключен — цикл завершается (событие `Completed`).
5. **Каждая волна сложнее** (камеры «учатся» на бою):
   - хп врагов умножается на `1 + StatsGrowthPerWave × номер волны` (повторы тоже считаются);
   - при каждом повторе последней волны к каждой её записи добавляется `ExtraEnemiesPerRepeat` врагов.

## Состояния (`WavesLoopState`)

`Idle → Wave ⇄ Delay → … → Completed`

| Состояние | Что происходит |
|---|---|
| `Idle` | цикл не запущен |
| `Wave` | идёт волна, ждём убийства её врагов |
| `Delay` | пауза между волнами |
| `WaitingForEnemiesKilled` | спавн остановлен (`StopSpawning` во время волны), ждём, пока добьют оставшихся |
| `Completed` | цикл завершён |

Логика — в `WavesStateMachine` (обычный класс), очерёдность волн и пауз — в `WaveSequence` / `DelaySequence`. `WavesLoop` — тонкая MonoBehaviour-обёртка.

## Конфиги

Создаются через **Create → SibJam**.

| Конфиг | Что внутри |
|---|---|
| `Enemy Config` | префаб врага (с компонентом `Enemy`), хп, скорость, атака |
| `Wave Config` | список врагов: `EnemyConfig` + количество |
| `Waves Loop Config` | список волн с паузой **после** каждой, галка `RepeatLastWave`, рост сложности: `StatsGrowthPerWave` (0.2), `ExtraEnemiesPerRepeat` (1) |

## На сцене

| Компонент | Зачем |
|---|---|
| `WavesLoop` | ведёт цикл. Поля: конфиг цикла и `WaveSpawner` |
| `WaveSpawner` | спавнит врагов в точках `_spawnPoints` (случайная, не равна предыдущей) |
| `WavesTrigger` | на коллайдере с `Is Trigger`. Игрок с тегом `Player` входит — волны стартуют, триггер выключается |
| `LocationTransition` | когда цикл завершился, переносит игрока в точку (старая схема, используется в `WavesTest`) |

Игроку нужен Rigidbody (можно кинематический), иначе триггер не сработает.

## API `WavesLoop`

- `LaunchWaves()` — запустить цикл
- `StopSpawning()` — больше не спавнить: из `Wave` → `WaitingForEnemiesKilled`, из `Delay` → сразу `Completed`
- `CompleteWaves()` — завершить сразу (живые враги остаются)
- `Completed` — цикл завершён
- `IsRunning`, `IsCompleted`
- `Info` (`IWavesLoopInfo`) — только чтение: `State`, `StateChanged`, `WaveIndex`, `AliveEnemiesCount`, `DelayTimeLeft`

## Тренировочные куклы

`TrainingDummy` автоматически объединяет активные куклы своей сцены в тренировочную волну.
До входа игрока на нижний этаж тренировочной зоны куклы скрыты, волны не запущены.
Первый вход запускает появление кукол и показывает общие панели волн и камер.
Вход определяется по позиции игрока: до 20 метров по горизонтали от кукол и на их этаже
(от 1,5 метра ниже до 2,5 метра выше исходной позиции). Камера на другом этаже не запускает тренировку.
Когда уничтожены все куклы, через 3 секунды вся группа появляется на исходных местах.
Цикл использует `WavesStateMachine` с бесконечным повтором, без роста характеристик и количества.
Первое появление и каждое возрождение проигрывают `EnemySpawnHologram` с шейдером
`Resources/EnemyHologramSpawn`. Исходные объекты остаются выключенными как шаблоны;
в бою участвуют их копии. Дополнительная настройка сцены не требуется.
HUD показывает оставшихся кукол, отсчёт до возрождения и камеры тренировочной зоны.
При выходе из зоны HUD скрывается, цикл волн приостанавливается; возвращение продолжает
текущую волну или отсчёт без повторного создания живых кукол.
Враги и куклы собираются снизу вверх тремя последовательными слоями: крупная красная сетка,
мелкая сетка, затем отдельные участки исходной модели. Участки постепенно заполняют поверхность,
сетка гаснет. Эффект длится 2,2 секунды, затем возвращает исходные материалы.
